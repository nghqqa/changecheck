# 演示视频脚本（目标时长 3 分钟）

> 录制方式建议：浏览器全屏 + OBS/Win+G 录屏，1080p，语速正常即可。
> 准备：`npm start`（或 docker compose up），确认 http://localhost:3000 可用、任务一报告 #1 与任务二报告 #2 已存在（演示数据已就绪）。
> 注意：全程不需要 API key 也能演示（讲历史报告 + mock 运行）。

## 录制要点

- 报告页展开样例时，停留 2 秒让观众看清字段级证据表（红底候选输出 vs 基线输出）
- 口播第 5、6 段是全片高光，放慢语速
- 无需出镜；结尾放仓库地址 + MIT 协议字样
- 导出成品：mp4，命名 `ChangeCheck-demo.mp4`，上传到 B 站/YouTube 获取链接填入提交邮件
