## 试用流程（引导语）

1. 打开首页，让其阅读价值主张 10 秒，问：第一眼知道这是干什么的吗？
2. 进入任务一，让其自己点「生成检查项」并勾选确认
3. 让其用自己的话描述一个自己业务里的要求，看解析结果是否符合预期
4. 展示"线上坏输出入库"，问：你的产品里有没有遇到过类似可以入库的错误？
5. 一起看报告 #1 与 #2，问：如果这是你的改版，你敢直接上线吗？
6. （可选）让其用 mock 模式发起一次运行
