# Milestone 0 · 验证实验

> 回答的问题（project-brief §6）：**用一小批明确样例，能否准确找出一次真实改版引入的新错误？**

## 设计

- **样例集** `samples.json`：36 条中文通知（正常 10 / 缺失 10 / 歧义 8 / 对抗 8），每条含参考答案 + 必须提取/必须留空的检查项 + 关键要求标注（这就是未来「要求引导引擎」要引导用户确认的东西，M0 先手工给出）。
- **两版本** `versions.json`：同一模型（deepseek-chat）、不同提示词——
  - 旧版：稳定提示词（逐字提取、缺失留空、取最终安排）
  - 新版：植入缺陷的「更完整可用」提示词（缺失补默认值 18:00/待定、相对日期换算、事件名正式化）——模拟一次真实的"好心改版"
- **管线**：执行器（并发调用、用量/耗时/费用记录、重试）→ 检查器（JSON/schema/字段级规则/参考答案对照；「该留空却补了值」恒为关键违规）→ 回归报告（新增失败优先、关键要求标红、费用耗时、采用建议）。

## 运行

```bash
# ① 无 key 验证链路（mock 模拟两版行为，验证检查器与报告，不代表真实模型）
node m0/run.js --mock

# ② 真实调用 DeepSeek（先设置 key；建议先 10 条试跑，再全量）
export DEEPSEEK_API_KEY=sk-xxx        # PowerShell: $env:DEEPSEEK_API_KEY='sk-xxx'
node m0/run.js --limit 10             # 试跑
node m0/run.js                        # 全量 36 条
node m0/run.js --reps 3               # 重要样例复跑 3 次
```

可选环境变量：`DEEPSEEK_BASE_URL`（默认 `https://api.deepseek.com`）、`DEEPSEEK_MODEL`（覆盖 versions.json）、`M0_PRICE_IN` / `M0_PRICE_OUT`（元/百万 token 计价，覆盖默认估算单价）。

产出在 `m0/out/`：`report-real-*.md`（报告）+ `results-real-*.json`（原始数据，可复跑对照）。

## 过关标准与当前状态

**最终真实结果**（deepseek-flash，2026-10-07，36 样例 × 2 版 × 3 次重复 = 216 次调用，报告 `m0/out/report-real-20261007131433.md`）：

| 标准 | 结果 |
|---|---|
| 植入退步 100% 被抓到 | ✅ **36/36**（新版全部出现关键违规：缺失字段凭空补全 / 相对日期擅换算 / 干扰日期采信 / 原文表述改写） |
| 稳定样例误报 ≈ 0 | ✅ 旧版 **36/36 通过、0 误报**；temperature=0 下仍有 2 条样例出现 1/3 次波动（A05 date 漏提取、A08 date/time 字段摇摆），被"3 次重复 + 多数决"吸收 |
| 总体对比 | 旧版 36/36、¥0.199、1190ms ｜ 新版 0/36、¥0.823、4630ms —— **新版更慢 ~4 倍、更贵 ~4 倍，且 36 条全部引入关键违规**，结论"不建议采用" |

经典案例 M01（"具体提交时间另行通知"）真实复现：新版 3 次全部补出 `time:"18:00"`、`location:"待定"`、并编造 deadline，与项目文档预测的缺陷完全一致。

**M0 结论：验证通过。** 用明确样例 + 字段级规则 + 新增失败优先报告，可以准确、零误报地找出一次提示词改版引入的新错误。

## 真实跑中发现的工程问题（已修，进产品经验库）

1. **思考型模型 token 上限坑**：deepseek-flash 会先思考再输出，max_tokens=400 时思考耗尽额度、正文为空（V07 现象：completionTokens=400 且 content=""）。→ 执行器必须给足 max_tokens（现 2000），且应检测"content 空但 completion 满"判为截断。
2. **event 字段是命名题不是逐字题**：年份/主办方前缀（"2026年秋季运动会"）、动宾语序（"提交实验报告"）不应判错 → 检查器对 event 放宽为包含/字符集等价，date/time/location/deadline 仍严格逐字（含数字保护，防 10月1日⊂10月17日 假近似）。
3. **参考答案标定是必要的人工环节**：A08"持续到今晚"date/time 归属在试跑后人工标定为 time（开始日期未给）；这类边界应沉淀进"要求引导引擎"的引导问题。
4. **temperature=0 仍有波动**：2/36 样例 1/3 次摇摆 → "多次重复 + 多数决 + 波动可见"应成为执行引擎默认行为（对应 product-vision 执行层"多次运行看波动"）。
5. 计价说明：报告费用按 deepseek-chat 单价常量估算（deepseek-flash 实际单价不同，以官网为准），趋势（新版更贵）不受影响。
